Responsable y alcance

Esta Política describe el tratamiento de datos asociado a Estudia+, una herramienta web de apoyo al estudio disponible en https://jorgehuaiquifilpichun-oss.github.io/estudia-mas-pruebas/. Para consultas sobre privacidad y ejercicio de derechos, escribe a jorge.huaiquifilpichun@gmail.com.

Datos utilizados

Para registrar e iniciar sesión se utiliza una dirección de correo electrónico y una contraseña a través de Supabase Auth. La aplicación también procesa los documentos que la persona decide subir o importar, así como información técnica necesaria para organizar su biblioteca, por ejemplo nombre, formato, tamaño y ruta del archivo.

Al usar herramientas de estudio pueden generarse o guardarse preguntas, respuestas, sesiones y resultados. Algunas preferencias o estados de actividades se guardan localmente en el navegador, mediante almacenamiento local.

Para qué se usan

Los datos de cuenta se usan para autenticar al usuario y permitirle utilizar la aplicación. Los documentos se utilizan para crear y consultar una biblioteca de estudio y para las actividades de lectura y práctica disponibles. Los datos de actividad pueden utilizarse para mostrar avances y recuperar sesiones.

Importación desde Google Drive

Si una persona elige «Importar desde Google Drive», Estudia+ solicita autorización de Google y abre el selector oficial de archivos. La persona elige qué documento importar. El archivo seleccionado se descarga temporalmente para enviarlo a la biblioteca de Estudia+; no se solicita acceso indiscriminado a todos los documentos de Drive.

El código de la integración utiliza el permiso https://www.googleapis.com/auth/drive.file. El token de acceso de Google se mantiene en memoria durante la operación y el código intenta revocarlo al terminar. Importar un documento crea una copia en la biblioteca de Estudia+; eliminar esa copia no borra el original que permanece en Google Drive.

Almacenamiento y proveedores

La aplicación utiliza Supabase para autenticación, almacenamiento de archivos y registros asociados. Utiliza servicios de Google para la selección de archivos y, en la función «Preguntas a la app», una función del servidor que consulta un servicio de inteligencia artificial. Los datos necesarios para prestar cada función pueden ser procesados por dichos proveedores de acuerdo con sus políticas y condiciones.

El código del navegador por sí solo no permite certificar la configuración efectiva de seguridad, las políticas de acceso, los respaldos ni los plazos de retención del servidor. Estas condiciones deben verificarse en la infraestructura antes de publicar esta política como declaración definitiva.

Eliminación y conservación

Desde la Biblioteca se ofrece una función para eliminar documentos importados o subidos. El código intenta eliminar el archivo almacenado y su registro, junto con los datos derivados vinculados según la configuración de la base de datos. Si una eliminación falla, puede quedar pendiente y requerir un nuevo intento.

Para consultar por la eliminación de información vinculada a una cuenta, escribe al correo de contacto. La conservación de registros técnicos y respaldos puede estar sujeta a los plazos propios de los proveedores utilizados.

Seguridad y acceso

El inicio de sesión se gestiona mediante Supabase. El acceso efectivo a documentos y registros entre cuentas depende, además, de las políticas de seguridad configuradas en el servidor. No debe interpretarse esta política como una garantía de seguridad absoluta.

Derechos y contacto

Puedes solicitar información o plantear una petición de acceso, rectificación o eliminación de tus datos escribiendo a jorge.huaiquifilpichun@gmail.com. Se atenderá según la normativa aplicable.

Cambios

El contenido de esta política puede actualizarse si cambia la forma en que Estudia+ funciona o trata datos. La fecha de la versión aparecerá al comienzo de esta página.
